How the radar prices a launch

implied value = 10(a + b · log10 TVL) × growth × maturity × chains

The curve is fitted to the snapshot’s own traded tokens — — — not typed in by hand. Every factor comes from the protocol’s own record: its TVL, its seven-day growth, how long it has run with no token, and how many chains it runs on. No protocol’s name ever changes its score. Each row also carries the band the backtest earns: the leave-one-out median miss, so a value of $10M is shown as roughly $3M–$34M, not as a false precision.

      Read this before farming

      “Pre-token” means the protocol’s record carries no token — no market cap, no CoinGecko id, no symbol — not that it has promised one. Implied value is a ranking model fitted to traded tokens, not a price prediction: it says which launch would be biggest if it happened, not that it will happen or what a token would trade at. The farm net is a scenario — 10% of the implied value shared pro-rata by TVL among depositors, on a $1,000 position — not a promise of any payout. Airdrops are never guaranteed, claims never ask you to pay, and the farm plans above are starting points, not advice. Verify every link on the protocol’s own site before you connect a wallet.
